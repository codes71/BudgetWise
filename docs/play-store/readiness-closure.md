## Local evidence and limits

The integration handoff records final commands, test totals, lint warnings, exact reviewed/pushed commit, CI receipts and no-deployment/no-release readback. Device evidence is synthetic and isolated. No connected-device Gradle task, owner-phone install, cloud AI call, production database operation or backup purge was used.

A new local account root restored from a synthetic old snapshot is denied by normal login/API/profile/write paths while the latest independent journal remains; deletion retry still removes it. A dry-run checksum cannot establish that a real journal export is complete/current, and the planner contains no restore writer.

The backend remains closed to cloud AI until an eligible operator configuration is explicitly authorized. IP geography is an additional restriction, not proof of residence or entity eligibility and never a VPN/server-location workaround.

The Better Design service returned HTTP402 quota exhaustion for principles/review/comprehension/spacing requests. Existing components/layouts/tokens remain; manual rendered checks and semantic tests are recorded without external visual-approval claims.
