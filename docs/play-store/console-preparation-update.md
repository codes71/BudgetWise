## Unsent classification question

Pocket Peek is an Android expense and budget record-keeping app. Users enter their own transactions, set category budgets and view their spending totals. Optional voice and receipt features extract draft entries for user review before saving. It does not transfer money, link bank accounts, offer loans, trade assets or recommend financial products. The linked website compares recorded category totals with user-set budgets using fixed informational text; it no longer generates personalized financial advice.

Does this functionality require an Organization developer account under the Financial Services rule, or may it use a Personal account? Which Financial features declaration choice accurately describes this Android functionality?

This remains an open classification question. Google's [account requirements](https://support.google.com/googleplay/android-developer/answer/10788890?hl=en) identify financial products/services as an organization category, while its [Financial Services definition](https://support.google.com/googleplay/android-developer/answer/9876821?hl=en) includes money management and personalized advice. No explicit primary budgeting exemption or app-specific ruling was established.
